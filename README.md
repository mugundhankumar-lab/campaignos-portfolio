# CampaignOS Portfolio Website

A React + Vite one-page portfolio for CampaignOS.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Concept projects are explicitly labelled as concept/spec work.
- No client results or testimonials are fabricated.
- Replace the concept cards with real portfolio assets as collaborations are completed.
- Update email/LinkedIn links if needed.
